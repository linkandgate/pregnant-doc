# 产检准备事项完整指南

> 产检准备因检查项目而异，核心原则是：**提前确认检查要求（空腹/憋尿/着装），带齐证件资料，备好应急物品**。以下按通用准备和专项检查分别整理。

---

## 一、通用准备（每次产检都适用）

### 1. 证件与资料

| 物品 | 说明 |
|---|---|
| **身份证** | 挂号、建档、身份核验必备 |
| **医保卡/社保卡** | 费用结算与报销 |
| **母子健康手册**（建档手册） | 每次产检必带，医生需记录 |
| **既往产检报告** | 方便医生对比数据、了解趋势 |
| **准生证/生育服务证** | 部分地区需要，视当地政策 |
| **银行卡/现金** | 备用支付 |

> 非户籍地建档可能还需**户口本或居住证**。

### 2. 随身物品

- **文件袋**：统一收纳母子健康手册、既往检查单、医保卡，避免遗漏。[reference:1]
- **便携零食**：全麦饼干、坚果、巧克力，应对抽血后低血糖或等待时间过长。[reference:2]
- **保温杯/水杯**：部分超声检查需要憋尿时快速补充温水；糖耐量试验需自备500ml水杯。[reference:3][reference:4]
- **纸巾/湿巾**：取尿样、内检后清洁用。

### 3. 着装建议

- 穿**宽松、分体式衣物**，方便露出腹部进行检查。[reference:5]
- 避免连体裤、紧身衣，超声和胎心监护时穿脱不便。
- 选择舒适平底鞋，减少长时间排队站立的不适。

### 4. 就诊技巧

- **错峰挂号**：不需抽血化验的产检，可选工作日下午，减少排队时间。[reference:6]
- **问题清单**：提前把想问医生的问题写下来，避免漏问关键事项。[reference:7]
- **电子存档**：用手机扫描所有报告，建立电子病历，方便随时调取。[reference:8]
- **提前预约**：NT、大排畸等超声检查通常需提前预约，大排畸建议提前1-2个月预约。[reference:9]

## 二、需要空腹的检查及准备

以下检查**通常需要空腹**，具体以医生要求为准。

### 1. 首次建档抽血（含肝肾功能、空腹血糖等）

- **空腹要求**：检查前一天晚上清淡饮食，检查前8-12小时禁食禁水。[reference:10]
- **建议**：将检查安排在上午，空腹抽血后及时进食，随身带好零食。

### 2. 唐氏筛查（15-20周）

- **空腹要求**：需要空腹抽血。
- **准备**：检查前一天晚上8点后停止进食饮水，早上空腹前往。[reference:11]
- **提示**：唐筛结果为“高风险”不等于确诊，需进一步通过无创DNA或羊水穿刺确认。[reference:12]

### 3. 糖耐量试验（OGTT，24-28周）★重点

这是准备要求最严格的一项检查，务必严格遵守。

#### 检查前3天
- **正常饮食**：维持日常饮食习惯，每日碳水化合物不低于150g，不要刻意节食或大量摄入糖分，否则结果不能真实反映糖代谢功能。[reference:13]

#### 检查前1天
- **禁食时间**：晚上22:00后停止进食，也不能饮用任何含糖饮料（果汁、可乐等），可适量喝白开水。[reference:14]
- **药物管理**：如正在服用降压药、激素、维生素等长期药物，**提前咨询医生**是否需要停药，部分药物可能干扰结果。[reference:15]
- **领取糖粉**：医生开单缴费后，提前到药房领取75g葡萄糖粉带回家备用。[reference:16]

#### 检查当天
- **空腹抽血**：一早前往医院完成第一次（空腹）血糖抽血，建议早上9:00前完成，减轻空腹不适。[reference:17]
- **自带水杯**：准备干净、容量至少500ml的水杯，方便配制糖水。[reference:18]
- **糖水配制**：将75g葡萄糖粉倒入杯中，加300ml温开水，充分搅拌至完全溶解、无颗粒。[reference:19]
- **饮用要求**：**5分钟内喝完**，从喝第一口开始记录时间，后续抽血均以此为准。[reference:20]
- **试验期间**：从喝第一口糖水到第三次抽血结束前，**严格禁食禁水**，避免呕吐，否则需重新检查。[reference:21]
- **抽血时间点**：喝糖水后1小时抽第二次血，2小时抽第三次血，全程约2小时。[reference:22]
- **家属陪同**：强烈建议安排家属陪同，长时间空腹抽血可能出现心慌、头晕等不适，需有人照应。[reference:23]

> 完成第三次抽血后即可正常进食饮水。若等待中出现心慌、出冷汗、胸闷等不适，立即告知医护人员。[reference:24][reference:25]

## 三、需要憋尿的检查及准备

**早孕期超声**（如孕早期B超确认宫内妊娠）通常需要憋尿，使膀胱充盈以便清晰观察子宫。

- **准备方法**：检查前1-2小时饮水500-800ml，等待膀胱充盈有尿意即可。
- **注意**：**孕中晚期超声通常不需要憋尿**，反而需要排尿后检查。[reference:26]

## 四、不需要空腹、不需要憋尿的检查

### 1. NT检查（11-13+6周）

- **饮食**：不需要空腹，正常吃饭即可。可适当吃巧克力、小饼干，让血糖升高，宝宝更活跃，便于医生获取清晰图像。[reference:27]
- **憋尿**：不需要憋尿。[reference:28]
- **着装**：宽松、方便穿脱的衣物，B超需露出腹部。[reference:29]
- **技巧**：前往医院途中可散步，增加活动量，有助于宝宝改变体位。若宝宝不配合，医生会让你休息15-20分钟，可继续吃零食、散步或轻抚肚子与宝宝交流。[reference:30][reference:31]

### 2. 大排畸超声（20-24周）

- **饮食**：**不需要空腹**，建议正常进食，饭后血糖升高可能让宝宝更活跃，有助于变换姿势。[reference:32]
- **憋尿**：**不需要憋尿**，检查前排尿即可。[reference:33]
- **着装**：穿宽松分体式衣物，方便露出腹部。[reference:34]
- **随身带**：少量高能量零食（如巧克力），若胎儿体位不佳，可进食或稍作活动后复查。[reference:35]
- **饮食调整**：检查前1-2天减少产气食物摄入，如豆类、洋葱、碳酸饮料，减少腹腔气体干扰。[reference:36]
- **需带资料**：身份证、申请单、既往检查报告单（NT报告或最近一次超声报告），并签署知情同意书。[reference:37]
- **心理准备**：检查时间可能较长（胎儿位置不配合时需等待），提前留出充足时间，放松心情耐心配合。[reference:38]

### 3. 胎心监护（32-34周开始）

- **饮食**：**避免空腹**，检查前1小时可少量进食，可准备酸奶、牛奶、水果、低糖饼干等健康零食适当加餐。[reference:39]
- **憋尿**：检查前**排空膀胱**，舒适体位更利于监测。[reference:40]
- **着装**：宽松易穿脱的衣物，上下分体式最佳，方便暴露腹部绑监护带。[reference:41]
- **时间选择**：摸清宝宝胎动频繁的时段（如上午10点、下午3点或晚饭后），选择宝宝活跃时做监护，更容易一次通过。[reference:42]
- **提前到达**：提前15分钟到医院，静坐稳定情绪，避免因妈妈心率过快影响数据。[reference:43]
- **若宝宝不配合**：可适当进食或播放音乐，刺激宝宝活动。[reference:44]

### 4. B族链球菌（GBS）筛查（35-37周）

- **无需空腹、无需憋尿**，检查无创、几乎无痛，几分钟完成。[reference:45]
- **检查前1周内**：不要使用抗生素。[reference:46]
- **检查前**：避免使用阴道洗液或栓剂，以免影响结果准确性。[reference:47]
- **检查当天早上**：尽量避免排便，建议前一天晚排空，或做完检查再上厕所。[reference:48]
- **个人清洁**：检查前一天做好个人清洁（洗澡或清洗下半身）。[reference:49]

## 六、必须立即就医的信号（无需等待产检）

无论处于哪一孕周，出现以下情况请立即就医：

- 持续剧烈头痛 + 视力模糊（警惕子痫前期）[reference:50]
- 胎动突然减少50%或剧烈躁动[reference:51]
- 阴道流血量超过月经量[reference:52]
- 破水后出现发热或浑浊液体[reference:53]
- 规律宫缩（10分钟3次）且未足月[reference:54]
- 严重腹痛、阴道流水

> **提醒**：以上为常规准备参考，具体检查要求请以产检医生的个性化安排为准。不同医院流程可能略有差异，建议提前电话确认。
