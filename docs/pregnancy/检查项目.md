# 孕期产检周计划（按孕周）

> 说明：孕期并非每周都有特殊检查，以下按孕周节点列出关键检查。未列出的孕周通常只需按医生安排的常规产检频率进行。具体产检时间和项目请以产检医生的个性化建议为准。

---

## 一、常规产检频率与每次必查项目

### 常规产检频率
- 孕 28 周前：每 4 周 1 次
- 孕 28-36 周：每 2 周 1 次
- 孕 36 周后：每周 1 次
- 孕 40 周后：每 3 天或遵医嘱

### 每次产检常规项目
- 血压
- 体重
- 宫高
- 腹围
- 胎心
- 尿常规（尿蛋白、尿糖）
- 孕晚期加：胎心监护

---

## 二、按孕周检查安排

| 孕周 | 检查频率 | 核心检查项目 | 备注 |
|---|---|---|---|
| 4-5 周 | 必要时 | 血 HCG、孕酮 | 确认怀孕，遵医嘱 |
| 6-8 周 | 一次 | B 超 | 确认宫内孕、胎心胎芽 |
| 9-13+6 周 | 建档 | 建档全套检查：血常规、尿常规、血型、肝肾功能、空腹血糖、乙肝、梅毒、HIV、甲状腺功能、心电图等 | 各地项目略有差异 |
| 11-13+6 周 | 一次 | NT 超声、早期唐筛 | 关键窗口期 |
| 14-15 周 | 常规 | 常规产检 | 每 4 周 1 次 |
| 15-20 周 | 一次 | 唐氏筛查（中唐） | 或已做无创 DNA |
| 16-18 周 | 常规 | 血常规、尿常规、血清铁蛋白等 | 遵医嘱 |
| 20-24 周 | 一次 | 系统超声（大排畸） | 需提前预约 |
| 24-28 周 | 一次 | 糖耐量试验（OGTT） | 需空腹 |
| 28 周 | 一次 | 常规产检、血常规、尿常规、B 超 | 进入孕晚期 |
| 30 周 | 一次 | 常规产检 | 每 2 周 1 次 |
| 32 周 | 一次 | 胎心监护开始、B 超、血常规、尿常规 | 评估胎儿发育 |
| 34 周 | 一次 | 胎心监护、常规产检 | |
| 35-37 周 | 一次 | B 族链球菌（GBS）筛查、胎心监护、B 超 | GBS 关键窗口 |
| 36 周后 | 每周 | 胎心监护、常规产检 | 每周 1 次 |
| 37 周 | 一次 | 胎位检查、骨盆测量、宫颈评估、B 超 | 分娩评估 |
| 38-40 周 | 每周 | 胎心监护、B 超（必要时） | 评估胎儿大小、羊水、胎盘 |
| 40 周后 | 每 3 天或遵医嘱 | 胎心监护、B 超、引产评估 | 过期妊娠管理 |

## 三、特殊检查窗口汇总

| 检查项目 | 建议孕周 | 说明 |
|---|---|---|
| NT 检查 | 11-13+6 周 | 早期排畸 |
| 早期唐筛 | 11-13+6 周 | 常与 NT 联合 |
| 无创 DNA | 12-22+6 周 | 具体遵医嘱 |
| 羊水穿刺 | 16-22 周 | 高风险或需确诊时 |
| 中唐筛查 | 15-20 周 | 评估染色体异常风险 |
| 大排畸超声 | 20-24 周 | 系统结构筛查 |
| 糖耐量试验 | 24-28 周 | 筛查妊娠期糖尿病 |
| 百白破疫苗 | 27-36 周 | 保护新生儿 |
| GBS 筛查 | 35-37 周 | 阳性需分娩时用抗生素 |

---

## 四、需要立即就医的信号

无论处于哪一周，若出现以下情况，请立即就医：
- 腹痛
- 阴道出血
- 阴道流水（破水）
- 剧烈头痛
- 视物模糊
- 严重水肿
- 胎动明显减少或异常

> 以上为常规参考，具体产检安排请严格遵循产检医生建议。
